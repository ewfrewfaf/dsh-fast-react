# 移植到其他环境

本包是**自包含**的：零运行时依赖，只用 Node 内置模块。换机器只要两步。

## 安装

1. 把 `dsh-fast-react` 放进目标机器的插件目录（或 `npm i <tgz>`）
2. 在 profile 的 `package.json` 的 `dsh.profile.bundles` 里加上 `"dsh-fast-react"`

DSH 启动时自动应用本包的 `cordis.patch.yml`。

## 黑板位置

按优先级自动解析，**无需手动配置**：

| 顺序 | 位置 | 说明 |
|---|---|---|
| 1 | `$FAST_REACT_BOARD` | 环境变量，显式指定 |
| 2 | `~/Desktop/FastReact` | 旧装机迁移（仅当已有 `.board/config.json`） |
| 3 | `$DSH_HOME/fast-react` | DSH_HOME 存在时 |
| 4 | `~/.dsh/fast-react` | 默认 |

## 模型

默认跟随全局默认模型。要指定快/慢模型，在控制台设置页或 `config.json` 里改：

```json
{
  "frontProvider": "", "frontModel": "",
  "backProvider": "", "backModel": ""
}
```

留空 = 跟随全局。

## Agent 预设

**不需要额外装 preset**。插件默认用 `standard`，前后台会话都能正常创建。

可选：若想启用带 `apply_patch` 的专用预设，在 profile 的 `cordis.patch.yml` 里加：

```yaml
- insert:
    - id: preset-fast-react-front
      name: '@deepseek-ai/dsh-agent-preset'
      config:
        id: fast-react-front
        order: 9
        plugins:
          - id: tool-fs
            name: '@deepseek-ai/dsh-tool-fs'
            config:
              applyPatch: true
```

## 端口

插件自身**不写死端口**——控制台挂到 DSH 当前的 web 端口下（`/fr`）。

审计/自检脚本会自动探测，也支持手动指定：

```bash
node tools/selfcheck.mjs 1890     # 第二个参数是端口
```

基准脚本的外部桥地址可用环境变量覆盖：

```bash
FR_BENCH_BRIDGE=http://127.0.0.1:8080/v1/chat/completions node tools/bench_single.mjs ...
```

## 验证

装好后跑一遍自检：

```bash
node tools/regression.mjs
```

期望：静态审计 / selfcheck 18 项 / UI-API 25 项 / 代码修复点 129 项 **全部通过**。

或打开控制台 `http://127.0.0.1:<port>/fr`，看前后台是否 `wired`。

## 已知的环境差异

| 项 | 说明 |
|---|---|
| **Windows 专用命令** | 部分示例用 `pwsh`；Linux/macOS 上插件会自动用 `bash` |
| **`magick`** | 只有重新生成 `icon.svg` 时才需要，日常运行不需要 |
| **`apply_patch` 预设** | 可选；不装则用默认 `write`/`edit` |

## 不随包发布的东西

以下**故意**在 `files` 之外，装到新环境不会带过去：

- `.board/`（黑板数据、会话记录、事件日志）
- `logs/`、`stale/`、`archive/`
- 编辑备份 `*.bak-*`
