## 附：编排会话的外围工具已禁用（2026-11-07）

`modes.js` 新增 `FR_NOISE_PATTERNS`，对**快速反应的前台/后台会话**硬禁以下工具（不影响你自己交互的会话）：

```
mcp_*  blender_*  aceternity*  video_*  storyboard*  image_*  dsh_image*
bili_* bilibili_*  netmon*  soft_gate*  whale*  send_wechat  plugin_health
tool_fold  skill_panel  skill_autoload  unlag*  cost_meter*  dshmarket*  ops_*
```

理由：这些会进工具表、占上下文、还可能被模型误调；编排任务用不到。
**作用域**：只在 `isFront(exec.agent) || isBack(exec.agent)` 时生效，走已有的 `tools.guard`。

### 需要某个工具时怎么放开

1. **单项放开**：设 `frDenyExtra: []`（空数组 = 不启用噪音表），或写成自定义正则数组只列你要抓的
2. **临时放开**：把 `cfg.frDenyExtra` 设成 `[]` 再重启，测完记得还原
3. 保留的白名单（永远不会被这张表拦）：`read write edit glob grep pwsh todo_write fr_* present web_*`

验证：

```bash
node -e "import('./lib/modes.js').then(m=>console.log(m.isDeniedTool('ops_bash'), m.isDeniedTool('read')))"
# true false
```
